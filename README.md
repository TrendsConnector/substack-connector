## How to ask

No keyword. Ask for the overall list or for one category.

**Good to know:** These are ranking lists. They do not include the subscriber count for one newsletter.

## FAQ

**Can I split Substack by category?**  
Yes. You can read the overall list or the same list by category.

**Does this return subscriber counts?**  
No. It is the ranking of top newsletters, not a count for one publication.

**Is the Substack connector free?**  
Yes. The free plan has 100 requests a month and includes every source. No credit card. Paid plans start at $19 a month for 1,000 requests.

**Which AI apps work with it?**  
Claude, ChatGPT, Cursor, VS Code, Claude Code, Grok, Muse, Perplexity, Gemini, Copilot, Windsurf and any app that supports MCP connectors.
